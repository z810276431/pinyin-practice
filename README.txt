学习练习小工具整合包（适配争渡读屏）
========================================

这是一个 Windows 学习练习小工具整合包。目前包含两个彼此独立的工具：

1. 拼音打字练习
2. 数学加减乘除算术练习

整合包启动器只是统一入口；两个工具也可以分别直接运行。

运行环境
--------
- Windows 7 及以上
- .NET Framework 4.x（Windows 自带）
- 推荐安装中文系统语音（简体中文 Windows 默认自带 Huihui 等）

使用方式
--------
1. 运行 PracticeToolkit.exe，打开“学习练习小工具整合包”。
2. 按 Tab 在“拼音打字练习”和“数学加减乘除算术练习”之间切换。
3. 按 Enter 或空格打开选中的工具。
4. 整合包窗口会继续保留，可以继续打开另一个工具。

也可以绕过整合包，分别运行：
- PinyinPractice.exe：拼音打字练习
- ArithmeticPractice.exe：数学加减乘除算术练习

三个 exe 文件必须放在同一个目录，整合包才能找到两个独立工具。

编译与测试
------------
1. 双击 build.cmd，生成：
   - PracticeToolkit.exe
   - PinyinPractice.exe
   - ArithmeticPractice.exe
2. 双击 test.cmd，编译并执行所有逻辑与键盘回归测试。
   测试会短暂打开窗口，但不会朗读，也不会修改用户词库。

一键发版
--------
双击 release.cmd（或在命令行运行），一条命令完成：
编译 -> 测试 -> 打包 -> 提交并推送 GitHub -> 创建或更新 Release -> 替换附件。

常用用法：

    release.cmd
        自动在当前最新标签上递增修订号后发版

    release.cmd -Version v1.2.0
        指定版本号（也可写成 1.2.0，脚本会自动补 v）

    release.cmd -Version v1.2.0 -Notes "新增：听写模式"
        Release 说明里的“本次更新”使用给定文字

    release.cmd -NotesFile notes.txt
        从 UTF-8 文本文件读取“本次更新”内容

    release.cmd -DryRun
        只编译、测试、打包并打印计划，不提交、不推送、不发 Release

    release.cmd -SkipTests
        跳过测试（不推荐）

    release.cmd -Force
        标签已存在且指向其他提交时，强制移动标签并覆盖推送

发版脚本会完成：
- 运行 build.cmd 与 test.cmd，任一失败立即中止，不会产生残缺发布
- 打包 dist\PracticeToolkit-<版本>-win.zip，并计算 SHA256 写入 Release 说明
- git add -A 后提交（没有变更则跳过）
- 推送当前分支与版本标签
- 创建或更新对应标签的 Release，删除同名旧附件并上传新附件
  （安装包、三个 exe、words.txt）

GitHub 凭据：
- 优先读取环境变量 GH_TOKEN 或 GITHUB_TOKEN
- 否则从 git credential 读取 github.com 的凭据
  （Windows 上通常由 Git Credential Manager 保存）

注意：发版会真实推送提交与标签，并更新 GitHub 上的 Release。
建议先运行 release.cmd -DryRun 检查版本号和打包内容。

拼音打字练习
--------------
功能：
- 系统语音播报词语读音，输入拼音后确认
- 正确/错误均有语音反馈；正确后进入下一题
- 支持预设词库、导入文字生成新词库、导出词库模板
- F5 重听时保留输入、光标和已有选区，不自动全选

快捷键：
- Enter / 空格   提交答案（仅在练习输入框内，空格不再插入字符）
- F5 / Ctrl+R    重新播报当前读音，保留输入和光标
- Ctrl+N         跳过当前词语
- Ctrl+I         导入词库（粘贴文字或从文件导入）
- Ctrl+T         导出词库模板
- Ctrl+L         重新加载 words.txt
- Esc            清空输入框

练习时建议连续输入拼音，例如 nihao，再按 Enter 或空格确认。
词库中的拼音仍可含空格，例如 ni hao；粘贴到输入框的 ni hao 也能识别。

拼音词库格式
--------------
words.txt 与程序放在同一目录，UTF-8 编码，每行一条：

    汉字|拼音
    汉字|拼音|朗读文本      （可选第三列，用于多音字指定读音）

例如：

    你好|ni hao
    学习|xue xi
    银行|yin hang|银行

说明：
- # 或 // 开头的行为注释，空行忽略；行内 # 之后也算注释
- 拼音带不带声调都可以，音节之间可用空格也可不用
- 判定答案时忽略声调、大小写和空格
- ü 可写作 ü、v 或 u:
- 支持 |、全角｜、制表符、逗号、分号、等号、冒号等分隔符
- 也支持“汉字 拼音”以及“1. 你好 ni hao”等格式

导入词库：
1. 按 Ctrl+I（或点“导入词库”）
2. 粘贴文字，或点“从文件导入…”选择文本文件
3. 选择替换或追加
4. 按 Ctrl+Enter 开始导入

导入窗口的空格仍正常输入，Enter 换行，不会触发练习确认。

数学加减乘除算术练习
----------------------
功能：
- 支持复合运算、加法、减法、乘法、除法五种模式
- 每种运算都提供“初级、中级、高级”三个级别：
  - 初级：两个数运算，求等号右边的结果，例如 2 + 4 = ?
  - 中级：两个数运算，问号可随机出现在第一个数、第二个数或结果位置，
    例如 ? + 4 = 6、2 + ? = 6、2 + 4 = ?
  - 高级：连续运算，额外启用“数量”选项，可选择 3、4、5 个数，默认 3 个
- 加法、减法、乘法、除法高级分别连续使用对应运算符
- 复合运算初级和中级随机练习加法或减法；高级同一道题中同时包含加法和减法
- 多个数的题目统一从左到右计算，界面和语音都会提示
- 支持 10 以内、20 以内、100 以内三个范围；所有中间计算结果均在所选范围内
- 除法题保证每一步都整除且除数不为零；减法和复合加减题不会出现负数
- 显示当前级别、题号、答对题数和答错次数
- 提供可聚焦的答题记录，方便读屏软件回顾
- F5 重听时保留输入、光标和已有选区，不自动全选

快捷键：
- Enter / 空格   提交答案
- F5 / Ctrl+R    重听当前题目，保留输入和光标
- Ctrl+N         换一题
- Esc            清空答案输入框

请输入问号所代表的整数。空格确认只响应单独按下空格；Ctrl+空格、Alt+空格等组合键不会提交。

争渡读屏适配说明
----------------
- 启动器和两个练习程序的主要控件都设置 AccessibleName / AccessibleDescription
- 所有核心流程均可仅使用键盘操作
- 状态文字直接表达当前进度及结果，记录区可通过 Tab 聚焦回顾
- 程序使用 Windows 系统 SAPI5 语音播报题目和对错
- 如果系统缺少可用语音，界面及键盘练习仍可正常使用
