拼音打字练习（适配争渡读屏）PinyinPractice
================================================

一个 Windows 桌面小工具，用来练习"听读音、写拼音"。
程序用系统语音播报词语读音，用户输入拼音后按 Enter 确认，
程序语音反馈"正确"或"错误"，正确后自动进入下一组词。
主要面向使用争渡读屏等屏幕阅读器的用户。

运行环境
--------
- Windows 7 及以上
- .NET Framework 4.x（Windows 自带）
- 需要系统已安装中文语音（简体中文 Windows 默认自带 Huihui 等）

编译与运行
----------
1. 双击 build.cmd，生成 PinyinPractice.exe
   （使用系统自带的 C# 编译器 csc.exe，无需安装 Visual Studio）
2. 双击 PinyinPractice.exe 运行

功能
----
- 启动后自动语音播报当前词语读音
- 输入拼音按 Enter 确认，语音播报正确/错误
- 正确后自动进入下一组词，错误可重试
- 按键重新播报读音（F5 或 Ctrl+R）
- 支持预设词库，也支持导入文字生成新词库
- 支持导出模板，编辑后重新导入

快捷键
------
- Enter          提交答案
- F5 / Ctrl+R    重新播报当前读音
- Ctrl+N         跳过当前词语
- Ctrl+I         导入词库（粘贴文字或从文件导入）
- Ctrl+T         导出词库模板
- Ctrl+L         重新加载 words.txt
- Esc            清空输入框
- Tab            在控件之间切换

词库格式
--------
words.txt 与程序放在同一目录，UTF-8 编码，每行一条：

    汉字|拼音
    汉字|拼音|朗读文本      （可选第三列，用于多音字指定读音）

例如：

    你好|ni hao
    学习|xue xi
    银行|yin hang|银行

说明：
- # 或 // 开头的行为注释，空行忽略；行内 # 之后也算注释
- 拼音带不带声调都可以，音节之间可用空格也可不用
  例如 ni hao、nǐ hǎo、nihao 都表示同一个词
- 判定答案时忽略声调、大小写和空格，输入 nihao 或 ni hao 都算正确
- ü 可写作 ü、v 或 u:
- 分隔符除竖线 | 外，也支持全角｜、制表符、逗号、分号、等号、冒号
- 也支持"汉字 拼音"空格分隔，以及 1. 你好 ni hao 这类带序号的行

导入词库
--------
1. 按 Ctrl+I（或点"导入词库"按钮）
2. 粘贴词库文字，或点"从文件导入…"选择 txt 文件
3. 选择"替换现有词库"或"追加到现有词库"
4. 按 Ctrl+Enter（或点"开始导入"）生效

导入成功后会写入程序目录的 words.txt 并立即开始新一轮练习。

词库模板
--------
- 导入窗口中"模板"按钮：把带说明的模板文本填入文本框
- 导入窗口中"另存模板并打开"：保存 词库模板.txt 并用记事本打开
- 主界面 Ctrl+T：把当前词库导出为模板文件并打开，便于修改后再导入

争渡读屏适配说明
----------------
- 主要控件都设置了 AccessibleName / AccessibleDescription
- 状态栏文字直接表达当前结果（正确/错误/进度），便于读屏软件朗读
- 练习记录区可通过 Tab 聚焦，用读屏软件回溯最近的状态与反馈
- 语音播报使用系统 SAPI5 语音，与读屏软件的声音互不冲突
- 若系统缺少中文语音，程序会退化为朗读拼音字母，功能仍可用
